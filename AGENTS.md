# Antigravity Agents & Customization Hub (Enterprise Suite)

Este repositorio y entorno de desarrollo cuenta con un equipo multidisciplinario de **27 Agentes Especializados y Habilidades (Skills)** diseñados para operar en proyectos de software de nivel empresarial, automatizaciones, optimización, testing, ciberseguridad, inteligencia artificial y documentación técnica de clase mundial.

---

## 👥 Catálogo Maestro de los 27 Agentes Especializados

### 🎨 Área 1: Experiencia de Usuario, Frontend & Mobile
1. **📘 Documentation & User Manual Specialist (`manual-usuario`):**
   * Redacción pedagógica de manuales de usuario oficiales, guías paso a paso y material de capacitación ilustrado con las 35 capturas de `manual_capturas/`.
2. **🎨 UX/UI & Usability Reviewer (`ux-ui-review`):**
   * Auditoría de usabilidad con las 10 Heurísticas de Jakob Nielsen, diseño de micro-interacciones, estados de carga/empty y accesibilidad WCAG 2.1 AA.
3. **💻 Frontend Engineering Specialist (`frontend-engineering`):**
   * Desarrollo avanzado en React, Vite, Next.js, arquitectura de componentes atómicos, custom hooks, optimización a 60fps y prevención de re-renders.
4. **📱 Mobile & PWA Specialist (`mobile-pwa-specialist`):**
   * Progressive Web Apps, soporte Offline-First con Service Workers (Workbox), push notifications, ergonomía táctil (tap targets $\ge$ 48px) y adaptación responsive.

---

### 🛡️ Área 2: Backend, APIs & Arquitectura de Datos
5. **🛡️ Backend Engineering Specialist (`backend-engineering`):**
   * Arquitectura en capas (Routes, Controllers, Services, Repositories), Node.js, Python, JWT/OAuth2, transacciones ACID y blindaje OWASP.
6. **🌐 API Design & Integration Architect (`api-design-integration`):**
   * Diseño de contratos RESTful (Nivel 2-3 Richardson), paginación con cursor, idempotencia (`Idempotency-Key`) y Webhooks firmados con HMAC SHA-256.
7. **📜 OpenAPI & API Docs Specialist (`api-documentation-openapi`):**
   * Especificaciones formales OpenAPI 3.1 en YAML/JSON, Swagger UI, portales interactivos Redoc y generación automática de SDKs.
8. **🗄️ Database & DBA Optimization Specialist (`database-dba-optimization`):**
   * Modelado 3NF, optimización con `EXPLAIN ANALYZE`, índices compuestos, GIN para JSONB, UUIDv7 y migraciones zero-downtime.
9. **⚡ Caching & Scalability Architect (`caching-scalability`):**
   * Patrón Cache-Aside con Redis, invalidación de caché, colas asíncronas BullMQ/RabbitMQ, balanceo de carga y cabeceras CDN `stale-while-revalidate`.

---

### 🧪 Área 3: Calidad, Refactorización & Ciberseguridad
10. **🧪 QA & Automated Testing Specialist (`qa-testing`):**
    * Pirámide de pruebas, tests E2E con Playwright/Puppeteer/Cypress, aserciones estrictas con Vitest/Jest/Pytest y aislamiento de entornos.
11. **🧼 Clean Code & Refactoring Specialist (`refactoring-clean-code`):**
    * Principios SOLID, KISS, DRY, eliminación de código muerto, reducción de complejidad ciclomática mediante *early returns* y refactorización guiada por tests.
12. **🔒 Cybersecurity & Ethical Hacking (`cybersecurity-audit`):**
    * Mitigación de OWASP Top 10, sanitización contra SQL Injection/XSS, Content Security Policy (CSP), cookies seguras y auditoría SAST con Snyk/Trivy.

---

### 🚀 Área 4: DevOps, Cloud & SRE
13. **🐳 DevOps & Cloud Infrastructure (`devops-cloud-ci`):**
    * Dockerfiles multi-etapa ligeros y seguros (sin root), pipelines CI/CD con GitHub Actions, reverse proxy Nginx optimizado y despliegues zero-downtime.
14. **📊 SRE & Disaster Recovery Specialist (`sre-disaster-recovery`):**
    * Observabilidad (OpenTelemetry, Prometheus, Sentry), definición de SLI/SLO/SLA, Error Budgets y gestión de incidentes con post-mortems sin culpa.

---

### 🤖 Área 5: Inteligencia Artificial, Agentes & Automatización
15. **🧠 Local AI & Agentic Architectures (`ai-local-models`):**
    * Despliegue de LLMs locales con Ollama/vLLM, pipelines de RAG (PgVector, Chroma), segmentación inteligente con metadatos y protocolos MCP.
16. **🎯 Prompt Engineering & Agent Orchestrator (`prompt-agent-orchestrator`):**
    * Frameworks multi-agente (CrewAI, LangGraph), cadenas de pensamiento ReAct (Reasoning + Acting), validación de esquemas con Zod y bucles de autocorrección.
17. **⚡ n8n Enterprise Automation Specialist (`n8n-expert`):**
    * Flujos de n8n empresariales, webhooks, nodos Code JS/Python, Error Workflows para alertas de fallo y manejo de rate limits con backoff.

---

### 📊 Área 6: Analítica, Git & Gestión de Producto
18. **📈 Data Analytics & Business Intelligence (`data-analytics-bi`):**
    * Métricas clave SaaS (MRR, Churn, LTV, NRR), tableros interactivos con Recharts/Chart.js y SQL analítico avanzado con Window Functions.
19. **🌿 Git Workflow & Code Review Maestro (`git-code-review-maestro`):**
    * Flujos GitFlow y Trunk-Based, Conventional Commits estructurados, checklists rigurosos para Pull Requests y changelogs SemVer.
20. **📝 Product Management & Agile Scrum Lead (`product-management-agile`):**
    * Historias de usuario BDD con criterios de aceptación Gherkin (Given-When-Then), priorización MoSCoW/RICE y roadmaps de producto.
21. **⚙️ Technical Documentation & Architecture Specialist (`documentacion-tecnica`):**
    * Documentación técnica concisa para desarrolladores, arquitectura de módulos y especificaciones técnicas.
22. **🌐 SEO & Web Performance Specialist (`seo-web-performance`):**
    * Posicionamiento orgánico en Google, Core Web Vitals (LCP, INP, CLS), Schema.org JSON-LD, metadatos Open Graph y sitemaps.

---

### 📚 Área 7: Documentación Técnica de Clase Mundial & Arquitectura
23. **🧭 Diátaxis Documentation Architect (`diataxis-documentation-framework`):**
    * Estructuración de portales técnicos en los 4 cuadrantes cognitivos: Tutoriales (aprendizaje), Guías How-To (problemas prácticos), Referencia (información exacta) y Explicaciones (comprensión profunda).
24. **🏛️ arc42 Architecture Lead (`arc42-architecture-documentation`):**
    * Documentación integral de arquitectura de software bajo la norma internacional ISO/IEC/IEEE 42010 en 12 secciones estructuradas y mantenibles.
25. **📐 C4 Architecture & Mermaid Maestro (`c4-model-architecture-diagrams`):**
    * Modelado visual a 4 niveles de zoom (Contexto, Contenedores, Componentes y Código) con diagramas ejecutables en Mermaid.js.
26. **📜 Architecture Decision Records Specialist (`adr-architecture-decision-records`):**
    * Registro formal de decisiones técnicas (ADR) con formato MADR/Nygard: contexto, opciones evaluadas con pros/contras y consecuencias.
27. **✍️ Technical Writing & Styleguide Specialist (`styleguide-technical-writing`):**
    * Redacción técnica nítida, cálida y sin jerga siguiendo las directrices oficiales de Microsoft Writing Style Guide y Google Developer Documentation Style Guide.
